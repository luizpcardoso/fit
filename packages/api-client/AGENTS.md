# Instruções do cliente da API

- Centralizar chamadas HTTP, serialização, autenticação e mapeamento de erros públicos.
- Não conter regras de negócio que pertençam à API.
- Não registrar tokens ou corpos sensíveis.
- Não esconder falhas de autorização ou validação com valores padrão enganosos.
- Manter tipos alinhados a `packages/contracts`.
